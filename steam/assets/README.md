# Steam artwork

`source/key-art.png` is the editable master scene. It was generated from the
live game and existing app mark as visual references. `source/logo.svg`
recreates the title lettering from room 00 as a transparent vector. The exact
built-in ImageGen prompt is preserved in `source/prompt.txt`.

Run this from the repository root:

```sh
sh steam/assets/build.sh
```

ImageMagick is required to rebuild the derivatives. The script writes:

- Store header capsule: 920 by 430 JPG
- Store small capsule: 462 by 174 JPG
- Store main capsule: 1232 by 706 JPG
- Store vertical capsule: 748 by 896 JPG
- Library capsule: 600 by 900 JPG
- Library hero: 3840 by 1240 PNG, without text
- Library logo: 1280 pixels wide, transparent PNG
- Library header capsule: 920 by 430 JPG
- Community app icon: 184 by 184 JPG
- Shortcut icon: 256 by 256 PNG

The generated directory is suitable for direct Steamworks upload. Steam store
screenshots must show actual gameplay and are not generated by this script.
